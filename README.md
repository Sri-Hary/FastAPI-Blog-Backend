# Blog Application Backend (FastAPI + MySQL)

## Project Overview
This project is a backend API built using **FastAPI** and **MySQL** for a simple blog application.  
It allows users to be created and blog posts to be managed using REST APIs.

The project demonstrates how to:
- Build APIs using FastAPI
- Connect FastAPI with MySQL using SQLAlchemy
- Perform CRUD operations
- Structure backend code properly

---

## Problem Statement
Many applications require a backend system where:
- Users can be created
- Content (posts) can be stored and managed
- Data is persisted securely in a database

---

## Solution
I developed a backend API that provides:
- User creation and retrieval
- Blog post creation, retrieval, and deletion
- MySQL database integration using SQLAlchemy ORM
- Clean and minimal FastAPI structure

---

## Tech Stack
- **Python**
- **FastAPI**
- **MySQL**
- **SQLAlchemy ORM**
- **Pydantic**
- **Uvicorn**
- **Postman** (for API testing)

---

## Features
- Create users
- Retrieve users by ID
- Create blog posts
- Retrieve posts by ID
- Delete posts
- MySQL database connection
- ORM-based models
